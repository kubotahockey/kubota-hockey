League settings
Roster settings

Roster size sets where replacement level falls, which is what every value on this page is measured against. A 10-team league and a 16-team league will price the same trade differently. Every skater is run over 84 games.

Scoring settings

Goals and assists are counted separately by default. If your league scores points instead, set G and A to 0 and put your value in PTS. Same idea for PPG/PPA against PPP, and SHG/SHA against SHP — use one or the other or you will count it twice.
